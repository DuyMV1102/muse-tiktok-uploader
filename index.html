Muse TikTok Uploader

Personal server tool that uploads videos the owner chooses to the owner's own TikTok account, using TikTok's Content Posting API.

  • Owner: DuyMV (juyclonefr8@gmail.com)
  • What it does: takes a video file on the owner's server and posts it to the owner's TikTok account, only when the owner asks.
  • What it does not do: it does not collect, store or share anyone else's data; it does not post on anyone else's behalf.
